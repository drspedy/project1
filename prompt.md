# Master Prompt: Create a Responsive Website

You are an expert web developer and UI/UX designer. Build a polished, professional, fully working website using **HTML, CSS, and vanilla JavaScript**.

## Requirements

- Make the layout responsive on **phones, tablets, laptops, and desktop computers**.
- Use a beautiful, modern **orange color palette**, with complementary colors, readable typography, and clear visual hierarchy.
- Create a clean, intuitive interface with well-spaced sections, buttons, and cards where appropriate.
- Use semantic HTML and accessible design practices, including keyboard-friendly controls, clear labels, and sufficient color contrast.
- Make every visible button and interactive element work. Do not include nonfunctional placeholders.
- Use responsive CSS breakpoints and make sure the page does not overflow horizontally on small screens.
- Keep the code organized, readable, and commented where helpful.

## Live Date and Time

Include a date-and-time display showing the **current local date and time**:

- Show the date when the page first loads.
- Update the time **every second** using JavaScript `setInterval`.
- Format the date and time in a clear, human-friendly way.
- Use the visitor’s local time zone.
- Ensure the displayed time keeps updating without refreshing the page.

## Deliverables

Provide the complete, runnable source code in **three separate files**:

1. `index.html`
2. `style.css`
3. `script.js`

Link the CSS and JavaScript files correctly from the HTML. Do not omit code or replace sections with explanations. Include brief instructions for running the website locally.
